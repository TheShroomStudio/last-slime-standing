# last-slime-standing
FR ONLY! un shooter un 2d vue de dessus, avec des vagues infinis d'ennemis, des bonus(coffres, lvl up, bonus de bosses) et 3 bosses qui apparaissent toutes les 60 secondes! Dans vet univers, vous êtes le dernier des slimes, et la grande armée des templiers sont prêt à tous pour vous exterminer! Combien de tant survivrez vous face à cette dernière croisade?
Features:
-arme princiaple: flingue (click gauche)
-coffres: quand vous avez assez d'or touchez les pour y prendre un bonus
-XP: quand la barre bleu se remplie tu lvl up! Et tu choisis entre 3 bonus
-dash: click droit pour faire un dash
-bosses: une sorcière, un roi, un viking, chacun apparait dans cet ordre, toutes les 60 secondes
-mutations: bonus surpuissant obtenu à la mort d'un bosse, il la lachera sur son là où il est mort
